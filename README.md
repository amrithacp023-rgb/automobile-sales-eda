# Automobile Sales Data Analysis – Exploratory Data Analysis (EDA)

## 1. Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on an Automobile Sales dataset using Python.

The main objective is to understand the company's sales performance and identify meaningful business patterns across different product lines, countries, years, months, deal sizes, and order statuses.

The analysis uses data visualisation and statistical techniques to identify sales trends and support better business decision-making.

## 2. Business Objective

The key business questions addressed in this project are:

- Which product lines generate the highest revenue?
- Which countries contribute the most to total sales?
- How does sales performance change over different years?
- Which months record the highest and lowest sales?
- Which deal sizes contribute most to revenue?
- What is the distribution of order statuses?
- What relationships exist between sales-related numerical variables?
